### 概要と目的

このドキュメントは **洞窟ダンジョン画像生成仕様書** です。  

mapgen_dungeon.md の屋内ダンジョン画像生成仕様をベースに、洞窟ダンジョンマップ画像生成の仕様を定義します。

- 1ピクセルが、1ブロック（1キャラと同サイズ）に対応する、2D RPGのダンジョンマップの画像を生成することを目的とします。
- 真上から見下ろしたトップビューのダンジョンマップ画像を生成します。
- レトロな2D RPGのように、1ブロックは、床、壁、通路、絨毯などのバイオームで構成されます。
- バイオーム色は「単色」です。色とバイオームは1対1で対応します。
- この画像を更に加工して、最終的なゲームのハイトマップやテクスチャマップを生成することを想定しています。
- 出力は png 画像です。バイオームを色分けして表示します。

---

### データモデルとフォーマット

#### png 画像
- 160x160ピクセルを標準とし、128x128～1024x1024までの範囲で生成可能です。
- 1ピクセルが、1ブロックに対応します。

#### バイオーム
**mapgen_world.md** の `MapGenBiomeID` と同じ数値を使用しますが、ダンジョンマップでは `PLAIN` が床、`MOUNTAIN` が壁、`ROAD` が通路、`BRIDGE` が絨毯などの意味に置き換えて使用します。
```cpp
enum MapGenBiomeID
{
	FLOOR_LV1 = 0,		//	標準的な床
	FLOOR_LV2 = 1,		//	ダンジョン内で高い場所にあるフロア。階段又は梯子で登る
	WALL = 3,			//	通行不能
	INNERWALL = 4,		//	壁の内側。上からは真っ黒に見える。
	LADDER = 6,			//	マップ内の段差を登るための梯子
	RIVER = 7,			//	FLOOR_LV1に所属する湖。通行不能
	LAKE = 8,			//	FLOOR_LV2に所属する湖。通行不能
};
```

### CaveMapImageGenerator 仕様

#### sample/cave内の画像を元に、洞窟ダンジョンの部屋、通路の作りについて特徴を分析し、仕様化する。
- 全体は黒背景上にくり抜かれた洞窟空間を掘っていく構造が基本。
  - 洞穴のような空間を掘り進めるため、通路はくねくねと曲線的で、直角折れは少ない。
- マップ内には階層が2段階あり、梯子で接続される。
  - 階層は、画像の下側から上側に向かって、1段目の床(FLOOR_LV1)から2段目の床(FLOOR_LV2)へ登る。
    洞窟的な迷路構造を作るため、階層間の接続は梯子(LADDER)で行う。
  - この階層構造が無いマップも存在する。有り無しはランダムで決定する。

#### 目標地形
- sample/cave 内の画像を参照。これらの画像のような、変化にとんだトップビューの洞窟マップ画像を生成することを目標とする。
- 床の中心線を先に引いて太らせる方式は採用しない。マップ内部を床候補として開始し、自然な形の壁塊を生成して洞窟空間を分割する。
- 部屋と通路を別々の図形として作らず、連続した密度場の広い部分を部屋、狭い部分を通路として扱う。これにより両者の境界を目立たなくする。
- 壁は Worley（ボロノイ距離場）と低周波 fBm を合成して作り、大きな岩塊、半島状の壁、緩やかに曲がる隙間を形成する。
- 一部の壁領域は地底湖 `LAKE` に置き換える。`LAKE` は壁と同じ通行不能領域であり、床の接続性やゲーム上の移動可能範囲を変化させない。
- カメラは画像の下側から上側を見下ろすため、湖は画像上側（`Y-`）に岩盤を背負い、画像下側（`Y+`）に床と接する岸辺が見える向きで配置する。
- ランダム性が高く、生成のたびに毎回違った意外性のある地形が生成される。
- 通路幅、壁塊の大きさ、空洞率、分岐密度、湖の配置などは、密度場のパラメータと seed により変化する。
- マップ内には比較的広い空洞が点在する。形は矩形ではなく、壁密度場から自然に生じる楕円、不定形、複数の空洞が融合した形とする。

#### 採用する生成方針

##### 壁密度場方式
- 基本状態は、外周を除くマップ内部を `FLOOR_LV1` とする。
- 各セルに対して壁らしさを表す連続値 `wallField` を計算し、しきい値以上のセルを `WALL` にする。
- `wallField` は、単一のノイズではなく次の要素を合成する。
  - 大スケール Worley: 大きな岩塊と空洞の配置を決める。
  - 中スケール Worley: 壁塊の輪郭を崩し、空間の大小差を作る。
  - 低周波 fBm: ボロノイ特有の均一さを崩し、壁を緩やかに蛇行させる。
  - 境界マスク: 外周に近いほど壁になりやすくし、十分な壁厚を確保する。
- 高周波ノイズは原則使用しない。最小のノイズ波長は 6～10 ピクセル程度とし、1ピクセルごとのギザギザを発生させない。

壁密度場の概念式は次とする。

```text
wallField =
	 largeWorley * largeWeight
  + mediumWorley * mediumWeight
  + lowFrequencyFbm * noiseWeight
  + borderMask * borderWeight
```

- Worley 値はそのまま使うだけでなく、seed ごとに反転や smoothstep を適用し、「母点付近が壁になる型」と「セル境界付近が壁になる型」を混在させる。
- しきい値 `wallThreshold` を上下させることで、床面積率と壁密度を直接調整する。

##### 薄い地形の除去
- 二値化直後の壁には、1～2ピクセル幅の壁ヒゲ、孤立壁、細すぎる床の裂け目が残るため、そのまま採用しない。
- 壁マスクに形態学的 opening（収縮後に膨張）を行い、`minWallThickness` 未満の細い壁や突起を床へ戻す。
- 床マスクに形態学的 opening を行い、`minPassageWidth` 未満の細い裂け目を壁で閉じる。
- その後、形態学的 closing（膨張後に収縮）を弱く適用し、小穴と1ピクセルの凹凸を除去する。
- `minPassageWidth` は 2 以上とし、通行可能と判定する床が局所的に1ピクセル幅にならないようにする。
- 単純な近傍多数決を何度も繰り返すと小空洞が消えすぎるため、距離変換を用いて「厚さ」を測り、対象となる薄い部分だけを変更する。

##### 接続性の保証
- 形態学処理後、4近傍 flood fill で床の連結成分を列挙する。
- 最大床成分を主洞窟とし、面積が `minRegionArea` 未満の孤立空洞は壁で埋める。
- 大きな孤立空洞は即座に削除せず、主洞窟との間で壁密度が最も低い鞍部を探索する。
- 鞍部の周辺を円盤状に床へ変換して二つの空洞を融合する。直線を引くのではなく、低密度領域を幅付きで開放するため、接続部も密度場由来の自然な形になる。
- 接続後に再度 flood fill を行い、通行可能床の 95% 以上が主洞窟へ属するまで、接続または小領域除去を繰り返す。
- 分岐数やループ数は通路を追加して作るのではなく、`wallThreshold`、Worley セルサイズ、壁 opening 半径の組み合わせで制御する。

#### 生成アルゴリズム概要
- 下記の手順で `MapGenBiomeID` の2次元配列を確定する。

1. 初期化
	- 全セルを一度 `FLOOR_LV1` とし、最外周 `borderThickness` セルを通行不能な安全領域として固定する。生成中は岩盤として扱い、最終分類では深い岩盤を `INNERWALL` にする。
	- 円・楕円・角丸矩形などの外形マスクで床を切り取らない。画像端へ近づくほど `wallField` を連続的に加算する edge pressure を使用する。
	- 左・右・上・下の edge pressure は、それぞれ独立した低周波 fBm で減衰距離を変化させる。これにより、各方向の通路が異なる深さで細くなり、壁へ自然に収束する。
	- edge pressure の範囲内には2次元 Worley 場による岩盤の張り出しを加える。外周を一枚の帯として閉じず、複数の大きな壁塊が外側から入り込む形にする。
	- 最外周の安全領域は、通常の壁密度によって床が十分手前で終了した後ろに隠れるため、矩形の切断面として見えないようにする。
2. 連続密度場の生成
	- 2種類の Worley 距離場と、2～4 octaves の低周波 fBm を生成する。
	- 座標を縦横で別々にスケーリングし、真円・正多角形に偏らない横長・縦長の壁塊も作る。
3. 壁塊の生成
	- 合成した `wallField` を `wallThreshold` で二値化し、壁塊を配置する。
	- 外周マスクを加算し、マップ端に接する厚い岩盤を形成する。
4. 壁の薄片除去
	- 壁の距離変換と opening により、細い壁、針状突起、小さな孤立壁を床へ戻す。
5. 床の狭窄除去
	- 床の距離変換により、幅が `minPassageWidth` 未満の床裂けを壁で閉じる。
	- closing で境界の1ピクセル凹凸と小穴を除去する。
6. 空洞の選別と接続
	- 床の連結成分を計測し、小空洞を削除する。
	- 残すべき大空洞は、壁密度の低い鞍部を局所的に開放して主洞窟へ接続する。
7. 床レベルの分類
	- `floorLv2CellSize` に基づく専用Worley母点群を生成する。
	- 正規化した母点Y座標と、母点固有ノイズ・低周波相関ノイズから各母点の有効深度を計算する。各画素では周囲の母点の有効深度を距離に応じて滑らかに補間し、Voronoiセル境界に値の段差が残らない連続場を作る。
	- 連続場からLV2候補セルを選び、候補から同じX座標の真上に連続する床へ上向き閉包を適用する。候補境界自体が連続曲線になるため、列ごとの深度段差や一定勾配の斜線を発生させない。
	- 残る床を `FLOOR_LV1` とし、壁・湖・床接続性は変更しない。
	- 分類後、`FLOOR_LV1` と `FLOOR_LV2` を別々に4近傍 flood fillして同レベルのアイランドを抽出する。
	- 面積が `minFloorLevelIslandArea` 未満で反対レベルに接するアイランドは、全セルを反対レベルへ置換する。最小アイランドから1つずつ統合して再抽出し、小さなLV1/LV2が同時反転して入れ替わることを防ぐ。
	- 後処理後のLV1/LV2境界を検査し、垂直連続長が画像高の `floorLv2MaxVerticalRunRatio` を超える場合は、壁・床・湖を固定したまま標高用seedだけを変更して床レベル分類を再生成する。
	- 最大 `floorLv2GenerationRetries` 回試行し、合格候補が得られなかった場合は垂直連続長が最短の候補を採用する。同一入力からの結果は決定論的に再現する。
	- 採用する標高候補を確定した後、各連続床区間のLV1/LV2境界へ低周波と中周波のfBmを合成した変位を加える。変位は上下最大 `floorLv2CliffStrength` セルに制限し、直線的な境界を自然な崖状の凹凸へ仕上げる。
	- 4セル以上連続する垂直なLV1/LV2境界にも、同じfBmをY方向へ評価して左右変位を加える。区間内のノイズ範囲を正規化して整数変位が一定になることを防ぎ、処理後に上向き閉包を再適用する。
	- 崖の凹凸は通行可能床セル内でLV1/LV2境界だけを動かし、最後に列ごとの上向き閉包を再適用するため、床マスクと下層から上層への一方向性は変更しない。
	- 元の崖境界から変位先までの8近傍に岩盤がある場合、LV2を縮小する向きの変位だけを禁止する。LV2を岩盤側へ広げる変位は許可し、`WALL` または将来の `RIVER` / `LAKE` とLV2の間に細いLV1膜を作らずに縦境界を崩す。
8. 湖の配置
	- 湖は床へ追加せず、`WALL` または `INNERWALL` の一部を `LAKE` に置き換える。このため湖の有無によって通行可能床は一切変化しない。
	- 円、楕円、矩形などの図形を水域の外形として使用しない。既に生成された壁トポロジーを湖の形として利用する。
	- 湖には「壁アイランド湖」と「岸壁湖」の2種類を設ける。
	- 壁アイランド湖は、外周岩盤に接続していない独立壁成分を4近傍 flood fill で検出し、面積と床への接触長が条件を満たす成分を丸ごと `LAKE` に置換する。輪郭の一部だけを切り取らない。
	- 岸壁湖の候補地は、画像下側 `Y+` に床が接し、画像上側 `Y-` に `lakeMinDepth` 以上の岩盤が続く壁セルとする。
	- 岸壁湖は候補セルから壁の中だけを priority flood で成長させる。優先度には低周波 fBm、壁深度、起点からの横距離、`Y+` 方向へのペナルティを使用し、岩盤に沿った入り江や枝分かれを形成する。
	- 成長した水域は常に4近傍で連結し、湖面の75%以上で画像上側に岩盤が残り、画像下側に3セル以上の床岸が存在する場合だけ採用する。
	- 湖の確定後、湖から壁内への距離と壁から床への距離を4近傍距離場で計算する。湖と床の間の実質的な壁帯厚が最大4セルとなる領域は `LAKE` に吸収し、直線だけでなく斜め・階段状・厚さが不均一な壁膜も除去する。
	- 距離和が上限を超える厚い岩盤は湖の背面壁として維持する。薄壁帯の置換は元の距離場から一括判定し、湖岸に沿って無制限に伝播させない。
	- 最終的な水域から岩盤内への4近傍距離を計算し、水域から3セル以内にある `INNERWALL` を `WALL` に変更する。湖と深い内壁を直接接触させず、岩盤側には3セル幅の通常壁を挟む。床と水域のセルは変更しない。
	- 複数の湖は十分に離して配置し、近接する小湖群が一つの人工的な模様に見えないようにする。
	- 最終的な水域を4近傍の連結成分として列挙し、隣接床に `FLOOR_LV1` が1セルでもあれば成分全体を `RIVER`、隣接床がすべて `FLOOR_LV2` の場合は成分全体を `LAKE` とする。隣接床がない水域は `LAKE` とする。
	- `RIVER` と `LAKE` はゲーム機能上は壁と同一で、所属する床レベルを示し、地底湖として認識させるためのバイオーム差分として扱う。
9. 壁種別と後処理
	- 床に近い岩盤を `WALL`、床から4セル以上離れた深い岩盤を `INNERWALL` として分類する。この分類は外周を含む全セルに適用し、マップの最外周はすべて `INNERWALL` にする。
	- 最終的な連結性、最小通路幅、床面積率を検査し、条件外ならしきい値を調整して最大 `generationRetries` 回再生成する。

#### バージョン2: 床の高低差
- バージョン1で確定した床マスクと接続性は変更せず、床セルだけを `FLOOR_LV1` と `FLOOR_LV2` に分類する。壁や湖を床へ変換しない。
- `floorLv2CellSize` を基準間隔とする専用Worley母点群を生成する。
- 各母点について、Y座標、母点固有のハッシュ値、複数セルにまたがる低周波の相関ノイズから有効深度を計算する。各画素の有効深度は周囲5x5セルの母点値を距離減衰付きで加重平均し、硬いVoronoi境界ではなく滑らかに蛇行する等値線を作る。
- Y座標とノイズ深度を混合するため、画像上側ほどLV2になりやすい傾向は保つが、画像下側も強いノイズ信号によってLV2候補になれる。
- `floorLv2Variation` が大きいほどY座標の寄与を弱め、ノイズ深度の寄与を強める。近隣セル間のまとまりを作りながら、深く張り出す領域、浅い領域、斜めに連なる領域をseedごとに変化させる。
- LV2候補マスクを画像下側から上側へ走査し、候補セルから同じX座標の真上にある床をLV2へ伝播させる。壁では伝播を停止する。
- したがって上下に連続する床を画像下側から上側へたどる場合、標高は `FLOOR_LV1 → FLOOR_LV2` の一方向にだけ変化する。上方向に `FLOOR_LV2 → FLOOR_LV1` と下がる配置は禁止する。
- 上向き閉包で境界形状を作らず、補間された有効深度場の等値線を境界形状として利用する。垂直や45度など特定方向へ長く固定された線を避け、洞窟の壁輪郭と同程度に不規則で滑らかな境界にする。
- 小アイランド統合後、左右に隣接する `FLOOR_LV1` と `FLOOR_LV2` の境界について、同じX位置で連続する長さを有限走査で計測する。画像高の `floorLv2MaxVerticalRunRatio` を超えた候補は不採用とする。
- 不採用時は元のmap seedから決定論的に派生させた次の標高用seedで、床レベル分類だけを最大 `floorLv2GenerationRetries` 回再試行する。洞窟形状、壁、湖および通行可能床は再生成しない。
- 全試行が基準を超えた場合は、垂直境界の最大連続長が最短の候補を採用する。
- 標高候補の採用後、LV1/LV2境界へ2帯域のfBm変位を適用する。`floorLv2CliffFrequency` で周波数、`floorLv2CliffStrength` で最大変位量を制御する。
- 長い垂直境界には左右方向の変位も適用し、処理前より最長垂直境界が長くなる場合は左右変位だけを取り消す。
- 崖変位の影響範囲が岩盤へ隣接する場合はLV2を縮小する変位を無効化し、LV2と壁・水域の間に1～2セル幅のLV1ノイズを作らない。
- 梯子と段差接続は別工程とし、このバージョンでは床の高低差分類のみを行う。

#### 推奨ランダム範囲
`-p key=value` を省略したパラメータは、次の範囲から個別に決定する。乱数は `seed` とパラメータ名から生成するため、同一 seed では同じ値を再現し、あるパラメータを明示しても他の未指定値は変化しない。

- `largeCellSize`: 22.0～38.0（大スケール Worley のセルサイズ）
- `mediumCellSize`: 9.0～19.0（中スケール Worley のセルサイズ）
- `largeWeight`: 0.35～0.60
- `mediumWeight`: 0.15～0.35
- `noiseWeight`: 0.20～0.40
- `noiseScale`: 0.015～0.040（最も細かい周期が高周波にならない範囲）
- `noiseOctaves`: 2～4
- `wallThreshold`: 0.50～0.62
- `borderThickness`: 4～6

#### デフォルトパラメータ
- **w**: 160
- **d**: 160
- **seed**: 任意の `uint32`
- その他の未指定パラメータ: 上記「推奨ランダム範囲」から seed により決定
- `-p` で指定したパラメータ: ランダム値を使用せず指定値を優先

#### 品質チェック指標
- 通行可能床の 95% 以上が最大連結成分に属すること。
- 床面積率が 0.30～0.55 の範囲に収まること。
- 1ピクセル幅の通路が存在せず、最小通路幅が2ピクセル以上であること。
- 面積48セル未満の孤立床領域が存在しないこと。
- 外周から床まで4ピクセル以上の壁厚を基本とすること。
- マップの最外周に `WALL` が存在せず、全セルが `INNERWALL` であること。
- 壁・床境界に、長さ3ピクセル以上の1ピクセル幅のヒゲが残らないこと。
- 湖を無効化した同一 seed の結果と比較して、差分が `WALL` または `INNERWALL` から `RIVER` または `LAKE` への置換だけであること。
- 各湖が4近傍で連結し、壁アイランド湖では選択した独立壁成分全体が置換されていること。
- 各水域成分は単一のbiome IDで統一され、`FLOOR_LV1` に隣接する成分は `RIVER`、それ以外は `LAKE` であること。
- 水域と `INNERWALL` が直接接触せず、岩盤が存在する側では水域から3セル以内がすべて `WALL` であること。
- `FLOOR_LV1` と `FLOOR_LV2` の合計が、バージョン1の通行可能床セル数と一致すること。
- `minFloorLevelIslandArea` 未満で反対レベルに接するLV1/LV2アイランドが残らないこと。
- 壁で分断されていない各列の連続床区間を画像下側から上側へ走査したとき、`FLOOR_LV2` の後に `FLOOR_LV1` が出現しないこと。
- LV1/LV2境界の垂直連続長が、原則として画像高の `floorLv2MaxVerticalRunRatio` 以下であること。全リトライが不合格の場合も、試行候補のうち最短のものを採用すること。
- 同一 seed とパラメータでは常に同一結果になること。

### ファイル構成とコードテンプレート

#### 以下の仕様については、既に作成されている WorldMapImageGenerator.(h|cpp) と同じ仕様にする。

#### ファイル構成
- `doc/mapgen_cave.md`（本仕様）
- `src/MapImageGenerator.h`（基底クラス。必要に応じて関数を追加）  
- `src/CaveMapImageGenerator.(h|cpp)`（基底クラス。必要に応じて関数を追加可）
- `src/utils.(h|cpp)`（Worley/Perlin/quantizeの実装。必要な機能を要生成）
- `src/main.cpp`（exeのエントリーポイント。入力からパラメータを取ったり、出力をしたり、png画像を生成する。必要な機能を要生成）
- `src/CMakeLists.txt`（CMakeビルド設定。必要に応じて生成）
- `src/build.bat`（ビルド用バッチファイル）
- `src/build/mapimggen.exe`（ビルドで生成される実行ファイル）
- `src/include/*`（ライブラリヘッダー。zlib,lpng等）
- `src/lib/*`（スタティックライブラリ）
- `bat/*`（ビルド、テスト用バッチファイル。必要に応じて生成）
- `/mapimggen.exe`（ビルドで生成される実行ファイル。bat/build.batによって生成）

#### MapImageGeneratorクラス
- MapImageGeneratorクラスは、マップ画像生成の基底クラスです。
- CaveMapImageGeneratorクラスは、MapImageGeneratorクラスを継承して、洞窟マップ画像生成の具体的な実装を行います。
- main.cpp では、コマンドライン引数を解析して、CaveMapImageGeneratorクラスのインスタンスを生成し、マップ画像を生成し、ファイル出力します。

#### テスト出力ディレクトリ
- `out/$session/$index_*.*`（自動テストとサンプル出力。1セッションで複数の出力）

#### mapimggen.exe のコマンドライン仕様

```
mapimggen.exe -type cave -w 128 -d 128 -seed 12345 [extra options] -dir tmp/mapgen/ -out filename [--data --png --report]
```

- `-type` : マップ生成器の種類。今回は `cave`で、`world`, `dungeon` なども追加されていく。
- `-w` : マップの幅（ブロック単位）
- `-d` : マップの奥行き（ブロック単位）
- `-seed` : 乱数シード。未指定の場合はランダム値を使用する。
- `[extra options]` : 追加パラメータ。`-p paramName=value` の形式で任意のパラメータを指定できる。
- `-dir` : 出力ディレクトリ。未指定の場合はカレントディレクトリに出力される。
- `-out` : 出力ファイル名。未指定の場合は `out` が使用される。
